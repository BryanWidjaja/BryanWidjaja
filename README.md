### 🚀 Featured Projects

- 🛡️ **[Byte-Image CNN for Malware Detection](https://github.com/BryanWidjaja/MalwareDetection)**  
A lightweight attention CNN that classifies Windows executables from raw bytes, without running them. It reached 0.988 ROC-AUC and a 1.14% false-positive rate on family-disjoint evaluation. Accepted at ICoAILO 2026.

- 🌾 **[Btardew Walley](https://github.com/BryanWidjaja/BtardewWalley-Refactored)**  
A terminal farming sim in Java with crops, livestock, a store economy, and save files. It's built on MVVM across 111 classes, using 8 GoF design patterns.

- 🏷️ **InstaTags** · [Frontend](https://github.com/InstaTags/FrontEnd) · [Extension](https://github.com/InstaTags/ChromeExtension)  
An AI hashtag generator for Instagram images. I built the SvelteKit web app and a Manifest V3 Chrome extension that pulls images straight from open Instagram tabs.
